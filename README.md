# 웹로그 예측 프로젝트

## 1. 프로젝트 설명

### 배경
이 프로젝트는 웹로그 데이터를 바탕으로 사용자의 행동을 예측하는 AI 모델을 개발하는 것을 목표로 한다. 웹사이트에서 발생하는 다양한 로그 데이터를 활용해, 사용자의 행동 패턴을 분석하고 이를 바탕으로 특정 목표 변수(예: 전환율, 거래 금액 등)를 예측하는 것이다.

### 목표
웹로그 데이터에서 피처 엔지니어링을 수행하고, 이를 기반으로 예측 모델을 학습하여 테스트 데이터의 목표 변수를 예측하는 AI 모델을 개발하는 것이 목표이다. 다양한 변수에 대해 적절한 전처리 및 인코딩을 적용하여 모델의 성능을 극대화한다.

## 2. 코드 설명

### 1. 데이터 로드 및 전처리
- **데이터 로드**: `train.csv`와 `test.csv` 파일을 불러와 데이터프레임으로 변환한다.
- **수치형 데이터 처리**:
  - `quality`, `duration`, `transaction`, `transaction_revenue`와 같은 수치형 변수를 로그 변환하여 데이터 분포를 정규화한 후, `MinMaxScaler`를 사용해 정규화한다.
- **범주형 데이터 처리**:
  - `browser`, `OS`, `device`, `continent`, `traffic_source` 등 범주형 변수는 라벨 인코딩을 통해 수치형 데이터로 변환한다.
- **결측치 처리**:
  - `keyword`와 `referral_path` 열의 결측치는 0으로 대체한다.
- **불필요한 열 제거**: `sessionID`, `userID`, `subcontinent`, `country`와 같은 예측에 불필요한 열을 삭제한다.

### 2. 피처 엔지니어링
- **피처 엔지니어링 함수**: 수치형 데이터에 로그 변환 및 정규화를 적용하고, 범주형 데이터를 라벨 인코딩한다. 그 외 불필요한 열은 삭제하고 결측값을 처리하는 과정을 포함한다.
- **피처 엔지니어링 수행**: `train` 및 `test` 데이터셋에 대해 피처 엔지니어링을 수행하여 모델 학습에 적합한 형태로 데이터를 변환한다.

### 3. 모델 학습 및 검증
- **데이터 배열 변환**: 학습 데이터를 NumPy 배열로 변환하여 모델 학습을 위한 준비를 한다.
- **교차 검증(K-Fold)**: `KFold`를 사용하여 데이터를 5개의 폴드로 나누고, 교차 검증을 통해 모델의 성능을 평가한다.
- **모델 학습**: 교차 검증을 통해 학습한 모델을 사용하여 각 폴드의 학습 세트에서 학습을 수행하고, 검증 세트에서 성능을 평가한다.
- **평가 지표(MSE)**: 각 폴드에 대한 예측 결과의 평균 제곱 오차(MSE)를 계산하여 모델의 성능을 평가한다.

### 4. 모델 예측 및 결과 저장
- **예측 수행**: 학습된 모델을 사용해 `X_test` 데이터에 대한 예측을 수행한다.
- **결과 저장**: 예측된 결과를 `submission.csv` 파일로 저장하여 제출 파일을 생성한다.

## 3. 데이터 설명

- **train.csv**: 학습에 사용될 웹로그 데이터로, 사용자의 세션 정보, 브라우저, OS, 기기 정보, 트래픽 소스 등 다양한 특성 변수가 포함된다.
- **test.csv**: 예측에 사용될 테스트 데이터로, `train.csv`와 동일한 구조를 가지고 있으며, 목표 변수는 포함되지 않음.
- **submission.csv**: 예측 결과를 저장하는 파일로, `sessionID`와 예측된 목표 변수를 포함.
